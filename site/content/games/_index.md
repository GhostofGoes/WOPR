WOPR knows fifteen games, listed in the order the film shows them, and tic-tac-toe, which is not on the
list. Every one is playable. Each game's page says how to play it, what to type, and how to win.

There are three ways to start a game:

- Name it on the command line: `wopr chess`, or `wopr 7` by its number.
- Log on, type `LIST GAMES`, and type a game's number or name.
- Ask WOPR for it by name: `Let's play chess.`

`wopr --games` prints the list with the shortest name each game answers to. Inside a game, press Esc twice
to leave it and go back to WOPR.
