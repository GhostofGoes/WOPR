{{- /* The install instructions, one tab for each system or way of installing, shared by the Quickstart and Installation pages so that the two never differ. With no argument, they are the download tabs (Windows, macOS, Linux): a download button, then what to click, with no command line. With "command-line", they are the lines to paste into a terminal (Windows, macOS, Linux (any), Linux (apt), Linux (RPM), Go). Hextra's tabs draw each set, synced: a tab picked on one page is picked on the other, and the two sets, whose tab names differ, are picked apart. js/install-platform.js picks the reader's system in each set they have not picked before. Each tab's text is Markdown in assets/install/.md, where @VERSION@ becomes the latest release's version (the version shortcode's), so that every download names a file that exists. @DOWNLOAD-@, a paragraph of its own, becomes two download buttons for that kind of file, one for each kind of computer, drawn here (install-download below; assets/css/custom.css styles them). Until the latest release has the Windows installer and the Mac app (the has-installers partial: every release after v0.4.0), their tabs show assets/install/download-later.md instead, with @LATER@ as what is to come. The same release is the first whose packages put WOPR in the app menu, so only then does @APP-MENU@ in the packages' tabs become the sentence in assets/install/app-menu.md (and, before it, nothing). Once the latest release is signed (the has-signatures partial), @SIGNATURES@ in the download tab's packages becomes assets/install/packages-signed.md (and, before, nothing), and the Linux (RPM) command line is assets/install/linux-rpm-signed.md in place of linux-rpm.md, where @KEYURL@ becomes the signing key's address on this site and @FINGERPRINT@ its fingerprint.
